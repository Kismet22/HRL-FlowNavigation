# Demonstration Videos

This folder contains demonstration videos for the HRL-FlowNavigation project. Each video showcases the performance of the trained hierarchical or standard RL agents under different tasks in unsteady fluid environments.

## Videos

1. **hovering.mp4**  
   Demonstrates stable hovering and disturbance rejection in vortical flow fields. The video shows both the agent's trajectory and the force profile over time in a single combined view, highlighting how the low-level controller compensates for flow perturbations.

2. **path_tracking.mp4**  
   Shows precise figure-8 trajectory tracking under time-varying flow, with both trajectory and force signals displayed together, illustrating the hierarchical controller’s ability to maintain the desired path while rejecting disturbances.

3. **navigation_obstacle.mp4**  
   Demonstrates autonomous navigation with obstacle avoidance. The video visualizes the agent navigating from a fixed start to a target while avoiding obstacles in a complex flow, with optional trajectory overlays for clarity.
